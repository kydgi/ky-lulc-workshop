NLCD

  • USGS National Land Cover Database 🔗
  • derived from Landsat imagery
  • categorizing land cover into 16 classes.

Original NLCD

  • Nine versions have been created (2001-2021)
  • each version is comparable to the others
  • but now they are legacy data.

Annual NLCD

  • Annual version starting in 1985 🔗
  • uses ensemble of deep learning models
  • each version is comparable to the others
  • but not to legacy data.

Data characteristics

  • Thematic raster with a Raster Attribute Table (RAT).
  • (most commonly) 8-bit integer data type.
  • 30 meter spatial resolution.
  • Yearly updates.

MRLC

  • Multi-Resolution Land Characteristics 🔗
  • suite of land cover products
  • guided by consortium of federal agencies.

Land Cover Explorer

  • KyGISServer Geoprocessing Service
  • Calculate statistics for two years
  • compare and return the results
  • as GeoJSON.

Land Cover Change Tool

  • Local tool uses KyGISServer Geoprocessing Service
  • Calculate statistics for two years
  • for certain types of change.
  • Returns stats and a 1-bit change raster.

Land Cover Change Notebook

  • ArcPy and Map Algebra
  • Spatial Analyst Extension needed.
  • Perform complex change analysis
  • Returns 1-bit change raster.
