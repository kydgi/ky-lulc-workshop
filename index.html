NLCD

  • USGS National Land Cover Database 🔗
  • derived from Landsat imagery
  • categorizing land cover into 16 classes.

Original NLCD

  • Nine versions have been created (2001-2021)
  • each version is comparable to the others
  • but now they are legacy data.

Annual NLCD

  • Annual version starting in 1985 🔗
  • uses ensemble of deep learning models
  • each version is comparable to the others
  • but not to legacy data.

Data characteristics

  • Thematic raster with a Raster Attribute Table (RAT).
  • (most commonly) 8-bit integer data type.
  • 30 meter spatial resolution.
  • Yearly updates.
